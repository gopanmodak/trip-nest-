# TripNext Blog Page

This is a **React** blog page for the **TripNext** travel website.  
It is built using **React**, **Tailwind CSS**, **DaisyUI**, and **React Icons**.

---

## 🔹 Features

- Responsive design (works on mobile, tablet, and desktop)
- Blog cards with image, title, description, date, and author
- DaisyUI styled buttons and cards
- React Icons for calendar, author, and read more arrow
- Hover effects on blog cards
- Grid layout for multiple blog posts

---

## 🔹 Technologies Used

- **React** – JavaScript library for building UI
- **Tailwind CSS** – Utility-first CSS framework
- **DaisyUI** – Tailwind CSS component library
- **React Icons** – Icon library for React
